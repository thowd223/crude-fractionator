Technical basis for engineering review

Status: proof of concept on illustrative data, not for design use. This section sets out the equations, constants, assumptions, solution method and checks so a process engineer can verify the work independently. Source files: model.js (engine), example_units.json (data), verify.py (independent check).

1. Header model

Steady-state, ideal-gas, molar mixing at one header node. No reaction, phase change or hold-up. A unit that is down produces no fuel gas and burns none.

Analysis of unit i y_ij = Σ_a w_ia · ŷ_aij a ∈ {lean, normal, rich}, w ≥ 0, Σ w = 1, ŷ normalised to 1 Component flow from unit i n_ij = F_i · y_ij F_i in [F_i,min , F_i,max] kmol/h Heat supplied by running units Q = Σ_i F_i · Σ_j y_ij · q_net,j / 1000 GJ/h Header heat demand D = Σ_running fuel_use_i + other consumers GJ/h If Q < D (short) N_NG = (D − Q) · 1000 / q_net,NG kmol/h, flare = 0 If Q ≥ D (long) N_NG = 0, flare = Q − D GJ/h (excess leaves as blended gas) Header mole fraction x_j = (Σ_i n_ij + N_NG · y_NG,j) / (Σ_i F_i + N_NG) MW = Σ x_j MW_j SG = MW / 28.964 LHV = Σ x_j q_net,j / 22.414 HHV = Σ x_j q_gross,j / 22.414 Wobbe (gross) = HHV / √SG H₂S ppmv = 10⁶ · x_H2S

q in kJ/mol (equal to MJ/kmol); dividing by 22.414 Nm³/kmol gives MJ/Nm³. Header heat is held at demand: NG makes up any shortfall and any surplus is flared. NG above the import limit is reported as a failure; it is not capped, because the header cannot then hold pressure.

2. How the range is found

For each scenario, every running unit may sit anywhere in its operating range: any flow between min and max, and any blend of its lean, normal and rich analyses. The envelope is the lowest and highest value of each property over all those combinations, then over all scenarios.

  • Exact for every property except Wobbe. On each side of the heat balance (short or long), each property is a ratio a/b with a and b linear in the unit flows. That is a linear-fractional program. It is solved exactly with Dinkelbach's method. Each step is a linear program with one coupling constraint (header heat), solved through its one-variable dual. The extreme is either a corner (every unit at min or max flow with a pure analysis) or a balance point (one unit between its limits so heat exactly meets demand).
  • Wobbe is searched, so its range is an estimate. HHV/√SG is not linear-fractional. Its extreme can lie part-way along a unit's range rather than at a corner: a hydrogen and methane blend has a lower Wobbe than either gas alone. The search starts from every optimum found for the other properties plus random corners. It alternates single-unit moves to any corner or balance point with continuous line searches, including paired moves that keep heat at demand, until neither improves. It matches a brute-force grid on a two-unit hydrogen/methane test built to have an interior minimum. A proven but much wider bound is HHVmin/√SGmax to HHVmax/√SGmin, from the exact HHV and MW extremes.
  • Each unit's analysis range is every blend of its named analyses. The example data uses lean, normal and rich. Real data can add engineer-selected samples, such as the highest-H₂S or highest-H₂ sample on record, without code changes, so that H₂S and H₂ extremes are not tied to MW.
  • Runtime is about 2 s for 19 scenarios in a browser.

3. Reference conditions and assumptions

  • Normal conditions 0 °C, 101.325 kPa. Ideal-gas molar volume 22.414 Nm³/kmol, Z = 1. Air MW 28.964.
  • Heats of combustion at 25 °C. Net = gross − n(H₂O) × 44.01 kJ/mol. The correction to a 0 °C or 15 °C combustion basis is ignored: about 0.3% on gross values (HHV, Wobbe), under 0.05% on net.
  • Wobbe is reported on a gross (HHV) basis, the usual burner-vendor convention. Confirm the client's reference conditions; ISO 6976 tables at 15 °C give different absolute values.
  • C4s are lumped as n-butane and C5+ as n-pentane. A heavier C5+ cut raises MW and heating value.
  • Each unit's fuel use is fixed at its normal value while running; it does not scale with throughput.
  • The analysis range of a unit is every blend of its named analyses. Real analyses fall outside it if the selected samples miss the extremes, so the selection must be checked against the history.
  • A unit that is down burns no fuel. That holds for a turnaround, not for a trip to hot standby with heaters on minimum fire.
  • Wobbe swing limit ±5%, H₂S limit 160 ppmv and NG import capacity 2,500 kmol/h are placeholders. The Wobbe band is centred on the typical header value because no burner design Wobbe is given; set wobbe_reference_mj_nm3 in the data once the burner design value is known.

4. Component properties used

Molecular weights and gross molar heats of combustion are standard values entered by hand. An independent review found them consistent with ISO 6976 and NIST values (methane 890.56 against ISO 890.63 kJ/mol, 0.01%). That review worked from memory, so the values still need checking against the published document (GPSA Engineering Data Book Section 23, ISO 6976 or the NIST Chemistry WebBook). Net and volumetric values are calculated from the gross column.

6. Not modelled

  • Real-gas behaviour, hydrocarbon or water dew point, condensation in the header or knock-out drums.
  • Transients during a trip: pressure swing, controller response, the delay before make-up catches up.
  • Meter error. Differential-pressure meters on fuel gas read wrong when MW changes; plant flows must be density-corrected before use.
  • Links between units beyond the scenario list, for example hydrotreaters cutting rate when the reformer is down and hydrogen is short.
  • Components outside the list: CO, O₂ (air leakage, for example vacuum ejector gas), NH₃, mercaptans, COS, H₂O. Butenes and other new components need a property row and a group mapping in the code before they count toward "Olefins" or "C4 and heavier".
  • Fuel use that changes with unit throughput, swing fuels (fuel oil, LPG vaporiser), flare gas recovery returning gas to the header, and amine-unit upsets as their own cause of high H₂S.
