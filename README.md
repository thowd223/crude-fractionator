# crude-fractionator

FEED-level engineering package for a **100,000 BPSD crude and vacuum distillation unit (CDU/VDU)**
processing Arab Light (33.4 API, 1.8 wt% S), developed from concept to engineering deliverables.

The whole package is generated by code: one process model (`cfu/`) feeds every drawing, list, datasheet and
report, so the disciplines stay consistent. Rebuild everything with:

```bash
pip install -r requirements.txt
python build.py              # all 12 stages, ~45 s
python build.py process pid  # or selected stages
```

Open `deliverables/06-wrapup/portal/index.html` for an indexed overview of all 102 documents.

## Design summary

| Item | Value |
|---|---|
| Crude charge | 100,000 BPSD, 568 t/h, Arab Light |
| Desalting | 2-stage electrostatic, 136 C, 5 LV% wash water |
| Preheat | 11 crude exchangers, CIT 274 C |
| H-101 atmospheric heater | 2-cell cabin, 8 passes, 67.4 MW fired, COT 366 C |
| C-101 atmospheric column | 6.9 m ID x 37 m, 41 valve trays, 3 pumparounds, 3 side strippers |
| Light ends | Stabiliser C-105, naphtha splitter C-106 |
| H-201 vacuum heater | 4 passes, 17.5 MW fired, COT 398 C |
| C-201 vacuum column | 6.6 m ID, 4 packed beds, 60 mbar(a) flash zone, 3-stage ejectors |
| Products | LPG, LN, HN, kerosene, diesel, AGO, LVGO, HVGO, slop wax, VR |
| Electrical | 13.8/4.16/0.48 kV, 4.5 MW maximum demand |
| Control | DCS + SIS + BMS + F&G, 859 I/O used; 3 MPC applications proposed |
| Cost | about USD 252 M ISBL total installed (AACE Class 4, 2026 USGC) |

| Folder | Contents |
|---|---|

## Repository layout

* `cfu/`: calculation and drawing generators (`hmb.py` process model, `sizing.py`, `pid/`, `mech/`, `layout/`,
  `piping/`, `elec/`, `ic/`, `wrapup/`)
* `data/`: master data exchanged between disciplines (JSON)
* `CONVENTIONS.md`: numbering, tagging, piping classes, plot frame and data ownership

## Accuracy

FEED (Rev A, issued for review). The process model uses pseudo-components with ideal VLE, so temperatures are
within about 5-10 C of a rigorous simulation. Confirm with a rigorous simulator on a full assay before detailed
design. Vendor items are marked TBD on the datasheets. The process design report and the portal list the open
items for detailed engineering.
